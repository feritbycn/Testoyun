# Premium system status

The UI describes a planned Premium tier, but no Premium entitlement is activated in this prototype. The purchase adapter is disabled, so no product unlocks.

Suggested production entitlement source:
- Verified store subscription status and expiry.
- Permanent “remove ads” entitlement.
- Cosmetic inventory unlocked by verified purchase.
- Premium daily bonus tracked on a trusted server if abuse prevention is important.

Recommended benefits from the design brief include removing forced ads, cosmetic bus paint/skins, extra saved custom designs, detailed company statistics, Premium missions and garage customization discounts. Avoid unlimited passenger capacity or other benefits that break the simulation economy.
